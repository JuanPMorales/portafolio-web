# Mi portafolio web

Bienvenido a mi portafolio personal.

Este proyecto es una página web desarrollada para presentar mi perfil como estudiante y desarrollador web, mostrar mis habilidades, compartir las tecnologías con las que trabajo y dar a conocer aquellas que estoy aprendiendo.

El portafolio cuenta con una interfaz moderna, adaptable a diferentes dispositivos (responsive) y diseñada para ofrecer una experiencia de navegación sencilla e intuitiva.
## Sitio publicado

Puedes visitar mi portafolio en el siguiente enlace:

**[Ver mi portafolio](https://juanpmorales.github.io/portafolio-web/)**

## Tecnologías utilizadas

Para el desarrollo de este proyecto utilicé las siguientes tecnologías y herramientas:

- **HTML5:** estructura y contenido de la página.
- **CSS3:** estilos y personalización visual.
- **Tailwind CSS:** diseño y estilización de componentes.
- **Git:** control de versiones.
- **GitHub:** almacenamiento y publicación del proyecto.
- **Font Awesome:** iconografía.
- **Google Fonts:** tipografía.

## Secciones del portafolio

El sitio está organizado en las siguientes secciones:

- **Inicio:** presentación principal y bienvenida.
- **Sobre mí:** información sobre mi perfil personal y profesional.
- **Habilidades:** conocimientos y competencias en desarrollo web.
- **Tecnologías que estoy aprendiendo:** herramientas y tecnologías que forman parte de mi proceso de aprendizaje.
- **Contacto:** medios para comunicarse conmigo.

## Ejecución local

Para ejecutar mi portafolio de forma local, sigo estos pasos:

1. Clono el repositorio y entro en la carpeta del proyecto:

   ```bash
   git clone https://github.com/JuanPMorales/portafolio-web.git
   cd portafolio-web
   ```

2. Instalo las dependencias del proyecto:

   ```bash
   npm install
   ```

3. Si necesito recompilar los estilos de Tailwind CSS, ejecuto:

   ```bash
   npx @tailwindcss/cli -i ./css/input.css -o ./css/output.css --watch
   ```

4. Abro el archivo `index.html` directamente en mi navegador.
